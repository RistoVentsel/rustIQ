RustIQ Server Type Implementation Plan

Goal
Add BattleMetrics-backed Rust server type support so the app can show, filter, and sort servers by Official, Community, or Modded.

1. Add server type to the backend domain
- Create a RustServerType enum in backend/src/RustIQ.Domain/Servers:
  - Unknown = 0
  - Official = 1
  - Community = 2
  - Modded = 3
- Add a ServerType property to Server.
- Keep the displayed type based on BattleMetrics details.rust_type.

2. Parse BattleMetrics server type fields
- Add ServerType to BattleMetricsServerSummary.
- In BattleMetricsServerDirectoryClient, read attributes.details.rust_type.
- Map values as:
  - official -> Official
  - community -> Community
  - modded -> Modded
  - missing or unknown -> Unknown
- BattleMetrics also exposes details.official and details.rust_modded, but rust_type should drive the user-facing Server Type because it maps to the Rust browser category.

3. Persist server type
- Add ServerType to the EF model in RustIqDbContext with string conversion and max length 32.
- Add an EF migration, for example AddServerType.
- Existing rows should default to Unknown until the next BattleMetrics refresh updates them.

4. Carry server type through ingestion and refresh
- Add ServerType to ConfiguredRustServer.
- Set it from BattleMetricsServerSummary during BattleMetrics discovery.
- Update existing Server rows with the latest ServerType whenever BattleMetrics-backed data refreshes.
- Steam/A2S-only servers should remain Unknown unless later matched with BattleMetrics.

5. Expose server type in API DTOs
- Add ServerType to ServerListItemDto.
- Add ServerType to ServerDetailsDto.
- Add ServerType to ServerDto if still used by any endpoint or test.
- Update ServerReadService mapping methods so /servers and /servers/{id} return the field.

6. Add filtering and sorting API support
- Extend GET /servers with a server type filter.
- Preferred query shape:
  serverTypes=official,community,modded
- No selected serverTypes means show all types.
- Add sortBy=serverType.
- Suggested ascending sort order:
  Official, Community, Modded, Unknown
- Descending reverses that order.
- Update repository filtering and sorting to support the new field.

7. Update frontend API types
- Add a RustServerType type/constant in frontend/src/api/types.ts.
- Add serverType to ServerListItem.
- Add serverType to ServerDetails.
- Extend GetServersParams with:
  - serverTypes?: RustServerType[]
  - sortBy?: players | lastWipe | nextWipe | location | serverType

8. Add clickable filter blocks below the search bar
- In ServersPage.tsx, add state for selected server types.
- Render three toggle blocks below the search bar:
  - Official
  - Community
  - Modded
- Blocks must be clickable and unclickable.
- No selected blocks means all server types are included.
- Any change should reset the page to 1.

9. Add a Server Type column to the list
- Add a Server Type header between Name and Players.
- Make the column sortable through sortBy=serverType.
- Update ServerListCard to render the server type as a compact badge/cell.
- Display labels:
  - Official
  - Community
  - Modded
  - Unknown

10. Add server type to server description
- Update the list card description line from:
  Map: ... PVE: False address
- To include:
  Map: ... Type: Official PVE: False address
- Also add the same server type information somewhere visible on the server details page summary.

11. Styling
- Update the server list CSS grid columns so the new Server Type column fits.
- Add styles for the three filter toggle blocks below the search bar.
- Add badge styles for server type:
  - Official: accent/green
  - Community: neutral
  - Modded: amber/orange
  - Unknown: muted

12. Tests and verification
- Backend tests:
  - BattleMetrics parser maps rust_type correctly.
  - GET /servers filters by serverTypes.
  - GET /servers sortBy=serverType returns deterministic ordering.
- Frontend verification:
  - Type filter blocks toggle on and off.
  - Server Type column displays correct labels.
  - Description line includes the server type.
  - Sorting by Server Type updates the list.
- Commands:
  dotnet test backend/RustIQ.sln
  npm --prefix frontend run build

Implementation note
BattleMetrics is the authoritative source for this field. A2S/Steam should not be treated as reliable for Official, Community, or Modded classification.
